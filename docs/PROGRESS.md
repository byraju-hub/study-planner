## 지금 하는 것
1단계는 `main`에 합쳤다. Cafe24 배포 묶음(`scripts/package.sh`)과 안내서(`docs/DEPLOY.md`)를 만들었고, Apache로 같은 구조를 흉내 내 통과를 확인했다. **실제 Cafe24 서버에는 아직 올리지 않았다** (접속 정보 필요 → 사용자가 직접 올리거나 안내서대로 진행).

4. 수행평가 모드: 수행평가·단계 체크리스트, 마감 경고

## 1단계에서 아직 없는 것 (의도적으로 미룸)
- 단원 순서 바꾸기(드래그): API는 `sort_order`를 받지만 화면은 아직 없음
- 교재 카탈로그(`book_catalog`)와 외부 연동: 5단계
- 회원 탈퇴, 비밀번호 찾기(이메일 발송): 미구현
- 업로드 파일의 이미지 외 PDF 미리보기: 새 탭으로 열기만 지원

## 확인 필요 (코드로 옮기기 전)
- 나이스 Open API 이용약관, 시간표 API 요청 변수
- 알라딘 TTB API의 목차 옵션, 호출 제한, 출처 표기 조건
- Cafe24 상품: www 바깥 폴더 사용 가능 여부, 서버 PHP 버전·확장(pdo_mysql, mbstring, fileinfo), HTTPS
- 사용자 범위(본인만 / 친구도) — 가입 승인제·초대코드 여부
- 배포 전: 업로드 폴더(`upload_dir`)를 웹에서 직접 열 수 없는 위치에 두기

## 메모
- 개발 환경: PHP 8.3 + MariaDB 10.11 (배포 대상은 PHP 8.4). 설치된 SvelteKit은 3.x라 예전 문서와 설정 방식이 다르다 (`CLAUDE.md` 참고).
